# MorningQuest

MorningQuestは、前夜の計画、朝のQRコード、日中のタスク進捗、夜のゲーム報酬をつなぎ、生活習慣の継続を支援するスマートフォン向けサービスです。指定場所に置いたQRコードを行動開始のきっかけにし、タスクの着手・完了をアイテムやバトルへ反映します。

## 開発概要

| 項目 | 内容 |
|---|---|
| 開発期間 | 3週間（15開発日を想定） |
| 開発体制 | 3名 |
| 役割構成 | バックエンド2名、フロントエンド1名 |
| 対象ユーザー | 生活リズムやタスク着手を改善したい学生・若手社会人 |

## 開発の優先順位

1. iPhone／AndroidのブラウザからHTTPS URLを開き、インストールなしで利用できるレスポンシブWeb版を完成・公開する。
2. Web版の必須要件と実機確認を完了した後、時間に余裕がある場合のみ、PWAのホーム画面追加やCapacitorによるAndroid／iOSアプリ化に進む。

モバイルブラウザでは、閉じたページを指定時刻に確実に起動して継続音を鳴らすことは保証できません。そのためWeb版の起床アラームは、前面表示中の動作を必須範囲とし、Web Pushやブラウザ通知は補助機能として扱います。

## 主な機能

- 前夜に翌日の起床時刻、就寝目標、習慣タスク、日次タスクを登録
- AIによるタスクのカテゴリ、所要時間、重み、推奨QRの分類
- 洗面所、PC前、玄関などに置いたQRコードによるアラーム解除・タスク着手
- 日中の進捗、残タスク、就寝見込みの表示
- タスク達成で獲得したアイテムを使う簡易バトル
- 通信断でも利用できる当日データとQR解除のオフライン対応

## 担当構成

| 担当 | 主な範囲 |
|---|---|
| BE-1 | 認証、ユーザー、プラン、タスク、DB、OpenAPI、就寝見込み |
| BE-2 | QR、アラーム、ゲーム、AI連携、Web通知、配備 |
| FE-1 | レスポンシブUI、QRカメラ、状態管理、オフライン、PWA、演出 |
